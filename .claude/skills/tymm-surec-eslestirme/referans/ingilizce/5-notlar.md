# İngilizce 5. sınıf – eşleştirme notları

- Yayınevi tabloları İngilizce'de beceri kodunu soru türüyle zayıf ilişkilendiriyor (ör. okuma
  sorusuna W6/S6, sözcük sorusuna L2). Bu yüzden İngilizce örneklerdeki çıktılar zayıf kanıttır; çıktı
  seçerken önce sorunun gerçekten ölçtüğü beceriyi (okuma → R2/R3, sözcük → V1, dil yapısı → G1) esas al
  ve güveni "düşük" ver.
- Yargı 6: kısa okul-yaşamı sorularının çoğuna konuşma bileşenleri (S3 d, S4 a/b/d), okuma sorularına R2 c /
  R4 c verdi; tema belirtmedi. İngilizce etiketleri içerikten tahmin edilemiyor; yayınevine özgü.
